# Робочий гайд українською — як подати SUTO OSNOVA на Devpost

Цей файл — **ваша інструкція зрозумілою мовою**. Саму форму на Devpost треба
заповнювати **англійською** — так вимагають офіційні правила, і англійською
сьогодні скануватимуть судді. Готові англійські тексти для копіювання лежать
поруч: [SUBMISSION_DRAFT.md](SUBMISSION_DRAFT.md) (там кожне поле пронумеровано
Field 1…Field 7).

часом — будете запізнені на добу.

## Крок за кроком: заповнення форми

1. Увійти на [qloo.devpost.com](https://qloo.devpost.com/) → **Join Hackathon**
   (безкоштовний акаунт Devpost).
2. Знайти кнопку **Enter a Submission** (вона з'являється після приєднання).
3. Заповнити поля — беріть готові рядки з [SUBMISSION_DRAFT.md](SUBMISSION_DRAFT.md):

| Поле форми | Що вставити | Звідки |
|---|---|---|
| Назва проєкту | рядок англійською | секція **Field 1** |
| Короткий опис (один рядок) | рядок англійською | секція **Field 2** |
| «What does your project do?» | головний опис (Markdown, копіюється разом із ```блоком) | секція **Field 3** |
| Try it! (лінк демо) | `https://suto-osnova.netlify.app` | секція **Field 4** |
| Code repository | `https://github.com/koztechie/suto-osnova` | секція **Field 5** |
| Built with (технології) | перелік технологій | секція **Field 6** |
| Ліцензія / подяки | MIT + Qloo | секція **Field 7** |

4. Перед натисненням Submit — пройти **чек-лист** (низ цього файлу).
5. Сабмітити. **Після 31 жовтня правки до submission заборонені** — сторінку
   проєкту в портфоліо Devpost оновлювати можна, саму заявку вже ні.
   Драфт у Devpost можна зберегти раніше і дописати — це дозволено.

## Що це за проєкт — коротко для себе

SUTO OSNOVA — агент, який перетворює культурний якір («David Lynch Noir»,
«Post-Punk Berlin», фестиваль) на готове культурне досьє через граф смаку Qloo
(250M+ сутностей). Три режими (світобудова подій, активація живих подій,
зворотній бік смаку), три формати експорту (JSON / Markdown / HTML-PDF),
без акаунтів і зберігання даних. Усі дані — тільки з чотирьох ендпоінтів
Qloo; якщо Qloo не відповідає — агент чесно відмовляється типізованою
помилкою, а не вигадує.

## Якщо нас назвуть фіналістом

- Ефір **5 листопада о 22:00 за Києвом** (прямий ефір із журі). Будьте
  на зв'язку заздалегідь — готуватися почнуть одразу після повідомлення.
- **Демо показувати так** (порядок на 2 хвилини):
  1. відкрити сайт — у футері видно «Powered by the Qloo Taste AI graph»,
     у шапці «Qloo link: online»;
  2. пресет **David Lynch Noir** → експорт Markdown;
  3. режим Experiential з якорем **Glastonbury Festival** → резонанс-індекс;
     **НЕ демонструвати пресет «Ambient Festival»** — він зараз віддає
     типізовану помилку `no_usable_signal` (задокументовано в
     [HOSTING_STABILITY.md](HOSTING_STABILITY.md)), у прямому ефірі це
     виглядало б як збій;
  4. відкрити **API Inspector** — журнал викликів і сирий провенанс Qloo
     (це і є доказ «якісно використовує Qloo»).
- **Пітч на 60-90 секунд** і **відповіді на питання журі** — готові
  англійською у секції *If you're named a finalist* у
  [SUBMISSION_DRAFT.md](SUBMISSION_DRAFT.md).

  06.11 — дедлайн **20.11.2026**. Пізніше або з помилками = дискваліфікація.
